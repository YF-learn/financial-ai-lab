# 📘 学习日志

> **核心理念**：记录失败不是示弱，而是把踩过的坑变成可复用的经验。  
> 频次：**一周一次**（建议每周日固定时间填写）。  
> 用法：复制下方【周模板】，修改日期即可开始记录。

---

## ✍️ 填写说明

| 字段 | 要写什么 | 怎么写更好 |
|---|---|---|
| **本周学会** | 新掌握的知识点、工具、方法 | 用一句话 + 关键要点，别抄定义 |
| **本周做成** | 完成的具体产出（作品、功能、报告） | 写结果，尽量可量化 |
| **本周 Bug** | 遇到的报错、异常、卡点 | 记录**现象 + 原因 + 解决方式** |
| **本周失败** | 没做出来 / 做砸的事 | 重点写**反思**，失败才有价值 |
| **本周理解** | 认知上的新突破、想通的道理 | 一句深刻的话胜过十句流水 |
| **下周** | 下周计划（3 条以内） | 具体、可执行，别列一堆 |

## 📖 使用 Tips

1. **Bug 一定要写原因**：只记报错信息 = 记流水账；写清「为什么」才是成长。
2. **失败要诚实**：这里只有你自己看，别美化，越真实越有用。
3. **下周计划别超 3 条**：能完成的计划才有意义。
4. **每月复盘一次**：把反复踩的坑归纳成检查清单。
